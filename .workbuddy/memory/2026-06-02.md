## 运行时修复
- **Store 延迟初始化**：BackupStore/ChannelStore/LogStore/SettingsStore/KeyVault 构造函数依赖 `app.getPath()`，从模块顶层移至 `app.whenReady()` 回调内
- **ELECTRON_RUN_AS_NODE 问题**：沙盒环境默认设置 `ELECTRON_RUN_AS_NODE=1`，导致 Electron 以 Node.js 模式运行（`require('electron')` 返回路径字符串而非 API 对象）。解决方案：通过 `scripts/dev.js` 和 `scripts/start.js` 清除该环境变量后启动 Electron
- **Electron 安装**：npm 安装 electron 遇到 EBUSY（Windows 文件锁），改用 yarn 安装成功；二进制下载使用 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`
- **Electron 启动验证**：`env -u ELECTRON_RUN_AS_NODE NODE_OPTIONS="" node_modules/electron/dist/electron.exe .` 成功启动，输出 "IPC 处理器注册完成"、"检测到 1 个已安装客户端"
- **.npmrc**：添加 `electron_mirror=https://npmmirror.com/mirrors/electron/` 国内镜像
